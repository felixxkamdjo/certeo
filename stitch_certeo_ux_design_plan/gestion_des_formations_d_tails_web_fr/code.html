Description

Ce programme immersif couvre l'ensemble du cycle de développement d'applications web. Les participants apprendront à créer des interfaces utilisateurs dynamiques avec React, à développer des API robustes avec Node.js, et à gérer des bases de données relationnelles et NoSQL. Le cursus inclut également des modules sur le déploiement cloud et les bonnes pratiques DevOps.
