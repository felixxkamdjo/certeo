# Module : Candidatures (`features/applications`)

## 📋 Périmètre Fonctionnel
- Liste et filtrage des candidatures par statut (En attente, Entretien, Accepté, Refusé)
- Fiche de détails du candidat (vue étendue)
- Envoi de mails individuels et groupés
- Formulaire public de candidature mobile en 4 étapes (Infos, Parcours, Expérience, Motivation)
